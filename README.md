Како да се стартува проектот:

1. Проверете дали имате инсталирано [.NET 8.0 SDK](https://dotnet.microsoft.com/download).
2. Отворете PowerShell или Терминал во фолдерот на проектот (каде што се наоѓа `Travel.csproj`).
3. Внесете ја и извршете ја следнава команда:

```bash
dotnet run
```
